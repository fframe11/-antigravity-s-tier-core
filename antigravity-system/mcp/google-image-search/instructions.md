# Google Image Search MCP Server Instructions

## Overview
The Google Image Search MCP server discovers authentic web images, technical architecture diagrams, product mockups, and real-world media to eliminate fake placeholders.

## Tools
- `search_images`: Search web images by query, returning authentic direct URLs, dimensions, and ready-to-paste `<Image />` JSX snippets.

## Usage Guidelines
1. Ingest real-world diagrams and technical reference images into developer dashboards and documentation pages.
2. Ensure every image component has explicit width/height and `object-cover` styling.
