# PickApIcon MCP Server

Fast icon collection and SVG retrieval server. Allows searching through icon repositories and pulling exact SVG code by description and prefix.

## Tools
- `get_icon_repos`: List all available icon repository names.
- `get_icons_by_desc_and_prefix`: Search icons by text description and collection prefix (e.g. `ant-design`, `lucide`, `heroicons`).
- `get_icon_detail_by_prefix_and_name`: Retrieve the exact SVG path/code for an icon by prefix and SVG name.
